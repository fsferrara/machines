# AGENTS.md

Projects are in this `workspace` directory.
The way they are organized reflects the following structure:

```
workspace/
├── personal/ (personal profile)
│   └── owner (the owner or the organization owing the projects)
│       └── project/ (the project name)
├── work/ (work profile)
│   └── owner (the owner or the organization owing the projects)
│       └── project/ (the project name)
└── other-profile/ (other profiles have the same structure)
    └── owner (the owner or the organization owing the projects)
        └── project/ (the project name)
```

## GIT preference

If available, @GIT.md lists the git configuration.
If available, @SSH.md provide instruction about how to clone repositories with ssh (preferred over https).
